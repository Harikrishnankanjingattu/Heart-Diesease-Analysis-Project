#  Heart Disease Data Analysis

This project focuses on **Exploratory Data Analysis (EDA)** of the Heart Disease dataset. The objective is to understand the dataset, identify patterns, discover relationships between medical attributes, and visualize important insights using Python data analysis libraries.

---

# 📊 Data Visualization

Data visualization helps reveal trends, patterns, and relationships within the dataset, making the analysis easier to understand and interpret.

### Visualization Techniques Used

- **Scatter Plots**
  - Analyze relationships between two numerical variables.
  - Example: Age vs. Cholesterol.

- **Line Plots**
  - Observe trends in continuous variables.
  - Example: Blood Pressure variations.

- **Bar Plots**
  - Compare categorical variables.
  - Example: Heart disease cases by age group.

- **Histograms**
  - Study the distribution of numerical features.
  - Example: Cholesterol levels.

---

# 📁 Dataset

The Heart Disease dataset contains patient medical information, including demographic details and clinical measurements.

### Dataset Features

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- ST Depression
- Slope
- Number of Major Vessels
- Thalassemia
- Heart Disease (Target)

# 🚀 Project Steps

## 1. Dataset Loading & Exploration

The dataset is imported and examined to understand its structure.

### Tasks

- Import required libraries
- Load the dataset
- Display dataset information
- Check data types
- View summary statistics
- Detect missing values

---

## 2. Age Distribution (DistPlot)

The **Age** column is analyzed using a distribution plot.

### Objectives

- Visualize age distribution
- Display histogram and KDE
- Identify common age ranges

### Observation

Most patients fall between **40 and 70 years** of age.

---

## 3. Categorical Analysis (Pie Charts)

Pie charts are used to visualize categorical variables.

### Categories

- Gender
- Chest Pain Type
- Heart Disease

### Objectives

- Show percentage distribution
- Compare different categories
- Identify class imbalance

### Observation

The dataset contains more male patients, and a significant percentage have heart disease.

---

## 4. Violin Plot Analysis

Violin plots combine density plots and box plots to compare numerical distributions.

### Objectives

- Analyze Age distribution
- Compare Gender vs Heart Disease
- Study Cholesterol levels
- Examine Resting Blood Pressure

### Observation

The plots reveal differences in feature distributions across various patient groups.

---

## 5. Correlation Analysis (HeatMap)

Correlation analysis helps identify relationships between numerical variables.

### Objectives

- Compute correlation matrix
- Generate heatmap
- Identify positive and negative correlations

### Observation

The heatmap highlights important relationships among medical features.

---

## 6. Joint Plot Analysis

Joint plots visualize relationships between two numerical variables.

### Objectives

- Age vs Maximum Heart Rate
- Cholesterol vs Age
- Scatter and regression analysis

### Observation

Joint plots provide a detailed view of trends and variable relationships.

---

## 7. Pair Plot Analysis

Pair plots compare multiple numerical variables simultaneously.

### Objectives

- Compare feature relationships
- Observe distributions
- Detect correlations and clusters

### Observation

Pair plots offer an overall understanding of interactions between numerical features.
